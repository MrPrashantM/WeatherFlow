# 🌤️ WeatherFlow

A beautiful, modern and feature-packed Weather Dashboard with stunning animations, effects and PWA support.

![WeatherFlow](https://weatherflowpm.netlify.app/preview.jpg) <!-- agar screenshot daalna ho toh -->

## ✨ Live Demo
**[🌍 Visit WeatherFlow](https://weatherflowpm.netlify.app/)**

## 🔥 Features

- **Interactive Map** with pulsing location pin
- **Dark / Light Mode** toggle
- **PWA** – Installable on any device
- **Realistic Weather Sounds** (Rain, Thunder, Wind, Birds)
- **24-Hour Temperature Chart** (Canvas)
- **World Clocks** for 7 major cities
- **Smart Browser Notifications**
- **Snow Effect**, **Lightning Effect** & **Twinkling Stars**
- **Temperature Unit Switch** (°C / °F)
- **Glassmorphism** UI + Smooth Animations

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Canvas Animations
- Service Worker + Manifest (PWA)

## 📁 Project Structure

| File             | Purpose                              |
|------------------|--------------------------------------|
| `index.html`     | Main structure                       |
| `style.css`      | Glassmorphism + Animations           |
| `app.js`         | Core logic & features                |
| `manifest.json`  | PWA configuration                    |
| `sw.js`          | Service Worker (Offline support)     |

## 🎮 How To Use

- City name search karo (Mumbai, Moscow, Dubai, Paris, etc.)
- 🌙 Button for Dark/Light mode
- 🔊 for Weather sounds
- 🔔 for Notifications
- 📍 for Current Location weather
